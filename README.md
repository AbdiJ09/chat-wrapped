# Chat Wrapped

Turn a WhatsApp chat export into a 3D film: thousands of glossy chat bubbles, one for every slice of your chat, that fly together into sculptures of it — who talks more, your hours, a city of every day, your favourite emoji — in a dark studio with a mirror floor. Pick a vibe (couple, bestie, squad, family, work), watch it like a story, save it as an MP4 or as images.

Everything runs in the browser. The chat never leaves your device.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

Built with three.js, WebCodecs and mp4-muxer.
